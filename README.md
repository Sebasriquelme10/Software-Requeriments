# ComunidApp

ComunidApp is a shared case-study project for the **Software Requirements Engineering** course at ITESO[cite: 1, 3].

## Project Overview

ComunidApp is a centralized digital application (both mobile and web) designed for the ITESO university community to aggregate, organize, and manage campus events, academic conferences, workshops, sports tournaments, and social activities in a single platform[cite: 3].

Examples of events and activities include:

- Academic conferences and departmental workshops[cite: 3]
- Sports tournaments and physical health activities (CEFSI)[cite: 3]
- Cultural festivals and artistic performances[cite: 3]
- Student collectives and USI initiatives[cite: 3]
- Campus orientation activities for first-year undergraduates[cite: 1, 2]
- Institutional annual events and sponsors' promotional activities[cite: 1, 3]

## Purpose

The project explores how a digital platform could:

- Centralize fragmented communication channels (emails, flyers, social media) into a single touchpoint[cite: 3].
- Improve event discovery and boost attendance across all student activities[cite: 3].
- Provide a unified event calendar synced with personal schedules[cite: 1, 3].
- Streamline check-in processes using unique QR codes[cite: 1].
- Enable real-time notifications, schedule change alerts, and automated waitlist updates[cite: 1, 2].
- Provide event hosts and administration with attendance metrics, survey analytics, and management tools[cite: 1, 2, 3].
