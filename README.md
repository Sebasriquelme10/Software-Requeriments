# ComunidApp

ComunidApp is a shared case-study project for the **Software Requirements Engineering** course at ITESO.

## Project Overview

ComunidApp is a centralized digital application (both mobile and web) designed for the ITESO university community to aggregate, organize, and manage campus events, academic conferences, workshops, sports tournaments, and social activities in a single platform.

Examples of events and activities include:

- Academic conferences and departmental workshops
- Sports tournaments and physical health activities (CEFSI)
- Cultural festivals and artistic performances
- Student collectives and USI initiatives
- Campus orientation activities for first-year undergraduates
- Institutional annual events and sponsors' promotional activities

## Purpose

The project explores how a digital platform could:

- Centralize fragmented communication channels (emails, flyers, social media) into a single touchpoint.
- Improve event discovery and boost attendance across all student activities.
- Provide a unified event calendar synced with personal schedules.
- Streamline check-in processes using unique QR codes.
- Enable real-time notifications, schedule change alerts, and automated waitlist updates.
- Provide event hosts and administration with attendance metrics, survey analytics, and management tools.
